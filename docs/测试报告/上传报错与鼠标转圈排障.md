# 上传报错 + 鼠标转圈 排障报告

日期：2026-07-21

## 一、用户反馈的两个现象

1. 前端上传视频后，弹出 `启动失败: Unexpected token '<', "<!doctype "... is not valid JSON`。
2. 视频监测主页面刚打开时，浏览器 tab / 鼠标一直是"加载中"转圈状态。

## 二、根因定位

### 现象 1：JSON parse error

从 `logs/flask_stderr.log` 抓到调用栈：

```
File "web/routes/monitor.py", line 83, in start_pipeline
    if task.status not in ("created", "stopped", "failed"):
AttributeError: 'AnalysisTask' object has no attribute 'status'
```

**根因**：`AnalysisTask` 模型没有 `status` 列（`status` 只在 `TaskRun` 上），但 `start_pipeline` 代码却在读 `task.status` 和写 `task.status = "running"`。Flask 抛未捕获 `AttributeError`，Werkzeug 返回 HTML 500 页，前端 `fetch(...).then(r => r.json())` 就报 `Unexpected token '<'`。

修复：

1. **纠正状态判定**：用最新的 `TaskRun` 状态代替 `task.status`：

   ```python
   latest_run = (TaskRun.query.filter(TaskRun.task_id == task.id)
                 .order_by(TaskRun.created_at.desc()).first())
   if latest_run is not None and latest_run.status in ("starting", "running"):
       return error_response("INVALID_STATUS", ..., status_code=409)
   ```

2. **删除所有 `task.status = ...` 赋值**。
3. **补 `TaskRun.config_snapshot`**（NOT NULL 无默认值）：`config_snapshot=_build_config_snapshot(task)`。
4. **注册全局 JSON 错误处理器**（`app.py`）：`/api/*` 下的任何未捕获异常一律返回

   ```json
   {"success": false, "error": {"code": "INTERNAL_ERROR", "message": "..."}}
   ```

   以后再有 bug，前端至少能直接显示错误码，不会再撞 HTML。

### 现象 2：鼠标一直转圈

flask 请求日志正常，页面 20 个左右静态资源，但打开 `/monitor` 时浏览器 tab 长期处于加载状态。

**根因**：`base.html` 从 `cdn.jsdelivr.net` 拉 Bootstrap CSS/JS + 图标字体。用 `Invoke-WebRequest` 实测：

```
jsdelivr OK 200 in 4103ms len=232803
```

**每次 4 秒**才能拿到 Bootstrap CSS，浏览器一直在等 CDN，主线程/loading spinner 就一直转。

修复：

1. 把 Bootstrap 全套 vendor 化到 `web/static/vendor/`：
   - `bootstrap.min.css`（233 KB）
   - `bootstrap.bundle.min.js`（81 KB，`defer`）
   - `bootstrap-icons.min.css`（86 KB）+ `fonts/bootstrap-icons.woff2/woff`
2. 加内联 SVG favicon（`data:image/svg+xml,...`），彻底消除 `/favicon.ico` 404。
3. 在 `app.py` 加 `/favicon.ico → 204` 兜底。

## 三、效果验证

### Playwright 加载耗时

修复前（等 jsdelivr）：约 4 秒才 `networkidle`。
修复后：

```
load_time_sec=0.85 readyState=complete title='AI 视频智能分析系统'
external_cdn_requests=0
```

### API 端到端

```powershell
POST /api/upload            → 201 { data.task_id: 1064 }
POST /api/analysis-tasks/1064/start-pipeline → 202 (完整 JSON runtime status)
POST /api/analysis-tasks/1064/stop-pipeline  → 200
```

不再出现 500 HTML。

### 单元测试回归

`pytest --ignore=tests/e2e` **231 passed**（含新增的 5 个 HLS 就绪单测），无回归。

## 四、面试可讲点

- **JSON parse error 排障链**：前端报 `Unexpected token '<'` → 意识到 fetch 收到 HTML → 去看 flask_stderr → 抓到 AttributeError → 补 status 判定 + 加全局 JSON 错误处理器（防御未来同类问题）。
- **CDN 拖慢诊断**：观察到打开页面异常慢 + tab loading 一直亮 → 用 `Invoke-WebRequest` 测 CDN 响应时间 → 4103ms 是主因 → 直接 vendor 化，同时消除 favicon 404 副作用。
- **架构收敛**：把"外部依赖"（CDN + jsdelivr）替换为"自托管"，展示"生产可用性 > 便利性"的取舍。
