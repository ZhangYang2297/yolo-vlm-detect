# YOLO 工程基准实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现可测试的 YOLO 行人检测器与 `YOLOv8n/YOLOv8s` 视频工程性能基准。

**Architecture:** 检测器通过后端注入隔离 Ultralytics，使单元测试无需下载权重或占用 GPU；基准层只消费结构化帧结果并聚合统计；CLI 负责视频 I/O、预热、资源采样和报告落盘。

**Tech Stack:** Python 3.10、Ultralytics、PyTorch CUDA、OpenCV、NumPy、psutil、pytest。

## Global Constraints

- 不训练模型，不引入人工标注流程。
- 只把 `person` 类别交给后续链路。
- 默认 `YOLOv8s`，使用 `YOLOv8n` 做性能对照。
- 首轮 `imgsz=640`、`batch=1`，统一测试条件。
- 未取得人工真值时不得输出项目 Precision、Recall 或 mAP。
- 所有性能报告必须记录实际设备、依赖版本与参数。
