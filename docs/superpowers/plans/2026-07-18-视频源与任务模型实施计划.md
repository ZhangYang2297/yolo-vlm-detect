# 视频源与任务模型实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将当前“任务直接保存source_url”的原型升级为独立视频源、可复用分析任务和可审计TaskRun控制面。

**Architecture:** `VideoSource`负责媒体地址、MediaMTX路径和探测状态，`AnalysisTask`只引用视频源并保存分析配置，`TaskRun`记录每次启动的配置快照与状态。Flask API只发出启动/停止意图；真正的Worker心跳与运行状态将在后续Worker阶段接入，当前不得把`starting`伪报为`running`。

**Tech Stack:** Flask 3、Flask-SQLAlchemy 3、Flask-Migrate/Alembic、MySQL 8.4、Pydantic 2、FFprobe、pytest 8。

## Global Constraints

- 保留旧`/api/tasks`兼容层，页面迁移完成前不删除`source_url/source_type`列。
- 新接口统一响应信封和`request_id`，旧接口保持现有返回结构，避免66项基线测试无关破坏。
- 本地文件只能位于配置的允许目录；探测命令使用参数数组且`Shell=False`。
- RTSP/RTMP/HTTP凭据不得出现在API响应、日志和错误消息中。
- 运行中的任务不允许修改视频源或关键分析配置。
- `TaskRun.config_snapshot`保存当次不可变配置；后续配置变化不改写历史。
- 阶段一只产生`starting/stopping`控制状态，只有Worker心跳才能确认`running`。
- 数据库迁移必须兼容已有开发数据库和全新空数据库，并记录回滚命令。
- 不在本阶段实现Redis Streams、Tracker、VLM、RAG、Saver或音频。
- 未经用户明确授权，不执行Git提交；计划中的每个任务以测试门禁替代提交步骤。

```python
def validate_source_uri(source_type: str, source_uri: str, allowed_roots: Sequence[Path]) -> str:
    if source_type == "local_file":
        resolved = Path(source_uri).resolve(strict=True)
        if not any(resolved.is_relative_to(root.resolve()) for root in allowed_roots):
            raise MediaSourceValidationError("LOCAL_PATH_NOT_ALLOWED")
        return str(resolved)
    parsed = urlsplit(source_uri)
    expected = {"rtsp": "rtsp", "rtmp": "rtmp", "http": ("http", "https")}[source_type]
    if parsed.scheme not in ((expected,) if isinstance(expected, str) else expected) or not parsed.hostname:
        raise MediaSourceValidationError("INVALID_SOURCE_URI")
    return source_uri
```
